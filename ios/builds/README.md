# builds/

Local drop-zone for downloaded **`.ipa`** files
(e.g. `DapperPOS-unsigned.ipa` from the
[latest release](https://github.com/FastXSkyline/DapperPOS-IOS/releases/latest)).

`*.ipa` files here are gitignored — they are build artifacts, not source.
Download with `../tools/download-latest-ipa` (Windows: the `.cmd`).
